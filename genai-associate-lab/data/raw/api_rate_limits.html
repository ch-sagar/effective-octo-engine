API Rate Limits

Limits per plan

Free plan: 5 requests per second. Pro plan: 50 requests per second. Enterprise plan: 500 requests per second, with burst up to 1,000 for 10 seconds.

Handling 429 responses

When you exceed the limit the API returns HTTP 429 with a Retry-After header. Use exponential backoff starting at 1 second with jitter. Do not retry immediately in a tight loop.

Request size

The maximum request body is 1 MB on Free and Pro, and 10 MB on Enterprise. Larger bodies return HTTP 413.

Timeouts

All requests time out after 30 seconds. Long-running jobs should use the asynchronous /v1/jobs endpoint instead.
